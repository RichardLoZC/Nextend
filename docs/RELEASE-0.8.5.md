# Nextend 0.8.5：菜单栏白线修复

2026-10-29。Mac 0.8.5 / build 17；Android 沿用原签名、原字节的 0.8.4 / build 18。

## 问题与修复

刘海折叠栏原先将原生菜单栏旁的 3 像素截图拉宽作为遮盖背景。图标向左移动、挨近应用菜单文字时，会把 Help 字母的边缘拉成贯穿菜单栏的白线。

现在从文字上方和下方留白的较宽范围取稳健中值，生成平滑背景，不再拉伸截图笔画。边缘颜色异常时改用稳健底色；无有效不透明像素时清空截图背景，使用系统底色。原截图布局、授权和生命周期检查保留。

## 一并公开的更新

- Wi-Fi 视频在短暂停顿后有有界恢复窗口；连接失效仍会结束并保留原因。
- Mac 和 Pad 本地轮换诊断日志、原生 ZIP 导出、共同会话编号；不会自动上传桌面或日志。
- 直接触屏双指落下即定位鼠标，滚动时鼠标保持原位置。
- 直接触屏与触控板支持捏合缩放，映射到应用的 Command +/−；不是原生连续 magnify。
- 直接缩放确认触点窗口后定向发送，避免缩放主屏的其他应用；新操作、关闭触屏及失效连接会撤销排队任务。

## 验证与边界

Mac 自检、恢复和日志测试通过。新增回归覆盖真实 Help 文字样本、深浅色菜单、密集文字、边缘污染、透明像素、极小图像、越界与非有限坐标；独立代码复审通过。真实旧菜单栏样本在第 23、24、35、36、37 行会出现白笔画，新背景无对应白行；当前 M4 上单次处理平均约 1.6 ms。

Android 未重新编译或更换签名。其 62 项单测及 0.8.4 的 12 组 Pad MotionEvent 测试、USB/Wi-Fi 实际浏览器手势验收见 [0.8.4](RELEASE-0.8.4.md)。本次 Mac 安装后的最终画面验收以项目私有 verification.json 为准。

Mac 为临时签名、未公证的 Apple Silicon 包；更新后 macOS 可能要求重新登记原有屏幕录制和辅助功能权限。系统授权必须由用户确认。未在本轮重验所有系统版本、HDR、所有第三方菜单插件或跨夜稳定性。
