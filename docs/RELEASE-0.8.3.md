# Nextend 0.8.3 · Wi-Fi 断线修复与诊断日志

日期：2026-10-28（Asia/Shanghai）。Mac build 15，Android build 17。保留原 Bundle ID、Android 包名、安装证书、配对和设置。

## 已复现的问题

在旧 Mac 0.8.1 / build 13 上，真实 Pad 的加密 Wi-Fi 桌面测试编码 39 帧、收到 35 个解码确认后，4 个在途帧占满队列。原 3 秒视频确认期限触发，Mac 主动关闭会话；Pad 返回等待连接并提示 Mac disconnected。Pad 原生日志显示后续帧约 3.17 秒后才到达，解码随即继续。旧版本 USB 30 秒对照测试完成，154 帧全部确认。

这说明该次断开的直接原因是短暂传输停顿触发了过早的视频超时。它不能证明所有 Wi-Fi 掉线都来自同一原因。

## 改动

- Wi-Fi SDR 和已验证 HDR 的视频确认期限改为 8 秒；USB 和未验证 HDR 的首帧处理保留 3 秒。原有控制通道和 socket 超时仍限制失联等待。
- 两端自动保存 JSONL 诊断日志，最多 4 个文件、每个 1 MiB。写入在后台进行，队列限制 256 条。
- 记录版本、系统、连接配置、会话编号、网络可用性变化、收发超时、视频错误、停止和清理原因；性能摘要每 15 秒记录一次。
- Mac 的显示器熄屏和系统睡眠分别记录。Android 启动时保存近期系统退出原因。
- 两端提供系统文件选择器导出 ZIP。导出仅包含日志、说明和存储健康摘要，不含画面、视频、触控坐标或配对文件。常见地址、设备序列号和凭据文本会被遮盖。
- 记录写入失败和排队丢弃数量；恢复未完成尾行后才轮换文件，避免导出不完整 JSON。Mac 正常退出有有界刷新；导出不携带 macOS 资源侧文件。
