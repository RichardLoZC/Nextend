# Nextend 0.6.0

## 变更

- Mac 新增“开启触屏”，默认关闭。连接中可切换“直接触屏”和“触控板”，退出应用后恢复关闭。触控板模式保留拓展桌面画面，并相对移动所有活动 Mac 显示器上的光标。
- 单指点按、双击；直接模式可单指拖动。双指轻点右键、移动滚动。触控板支持单指轻点后再次按住拖动、三指拖动、四指切换桌面／窗口总览，以及双指捏合缩放。
- Pad 投屏菜单取消。FPS 开关、位置、颜色、字体、字号和性能诊断集中到 Mac“Pad 设置”。Mac 的中英文按钮同步 Pad 语言，FPS 浮层不再截获触摸。
- Pad 等待页新增“连接”，USB 请求成功后实际使用 USB 视频，无线请求沿用 Mac 画质。首次仍需从 Mac 用 USB 配对，后续通过 USB 反向连接或 Bonjour 发现发起经过认证的请求。Mac 必须保持运行，窗口可以关闭。
- 无线由 Pad 主动建立视频 TCP，并重新认证；无需 Mac 拨入 Pad。保持现有 VPN 配置，完全禁止局域网访问的 VPN 仍可能影响无线。
- Mac 接受请求后若 20 秒仍未建立视频连接，Pad 显示超时提示，可重新尝试。
- 关窗后隐藏 Dock 运行图标，保留状态栏和连接；重新开窗恢复图标。此项包含此前未单独发布的本地 0.5.1 修改。
- “重新配对”移到 Mac 菜单，立即撤销本地授权；旧会话、未完成的配对和 HDR 回退不能恢复已撤销的密钥。

## 手势与系统限制

滚动方向跟随 Mac 的自然滚动偏好。捏合映射到 Command +/−，四指滑动映射到 Control + 方向键，效果取决于应用及系统快捷键设置。未实现压力、旋转或原生连续缩放，不覆盖 Apple 触控板的全部手势。

实测 Pad 7 Ultra 的三指及以上操作仍被小米系统拦截。单指和双指操作已由用户确认正常。新增单指轻点后再次按住拖动，作为三指拖动受限时的替代操作。

普通 Android App 没有禁用所有厂商手势的通用接口。小米官方说明可在支持的系统中使用 Game Turbo 的“限制截图手势”，但用户在当前 Pad 找不到该入口；此方法也不能保证屏蔽分屏或其他手势。Nextend 不修改全局手势设置。参见[小米官方说明](https://www.mi.com/global/support/faq/details/KA-673391/)。Android 的[手势排除区域](https://developer.android.com/develop/ui/views/touch-and-input/gestures/gesturenav)主要用于边缘返回冲突，不能据此承诺屏蔽小米三指截图。

| Android 构建及单元测试 | 31 项通过，其中 16 项覆盖手势、轻点后拖动与坐标 |
| 触屏与设置协议真机检查 | 构建 9 的 9 组通过：开关切换、协商、代次、布尔类型、消息方向、触控板模式及设置边界 |
| Pad 发起连接协议检查 | 10 组通过：包长度、协议域分离、认证、额外字段、重放、篡改、序号、握手超时及空闲 resume 拒绝 |
| 原有视频协议真机检查 | 构建 9 的 8 组通过：超长包、认证失败、重放、标签篡改、反向输入、HDR 非法配置、旧客户端及握手总超时 |
| USB 连接与 Pad 主动连接 | 构建 9 从 Mac 与 Pad 发起均通过。用户确认 Pad 按钮连接成功；Mac 原选无线，实际自动改用 USB，已核对 ADB 视频转发与 loopback 会话；sing-box 保持开启 |
| 请求后的失败提示 | 真机确认：Mac 无法建立视频连接时，Pad 会由“等待 Mac”转为超时提示 |
| Mac 设置同步 | 实测 FPS 开关、字号和位置同步至 Pad；中英文界面检查通过 |
| 安装与权限 | 构建 9 两端已安装；移除旧记录并重新加入当前 App 后，录屏与控制权限恢复有效 |
| 三指、四指真机操作 | 用户确认仍被小米系统拦截；尚未通过验收 |
| 单指、双指与滚动方向 | 用户确认均正常 |
| 单指轻点后拖动 | 单元测试通过，等待真实手指验证 |
| VPN 开启时无线连接 | sing-box 保持开启，Mac 发起 SDR / HDR 均通过；视频复用 Pad 出站 TCP，USB 视频转发为空，HDR 输出格式已确认 |
| Pad 通过 Wi-Fi 按钮发起连接 | 待独立真机点击验证；同一出站视频路径已从 Mac 验证 |
| 小米系统手势拦截 | 用户找不到 Game Turbo 入口，未解决当前设备的拦截 |

独立代码审查覆盖连接请求认证、配对撤销、异步回调代次、套接字关闭、输入取消和相对坐标累加。另覆盖自动探测抢占手动请求、ACK 与超时交叉、旧解码器未释放时的反向移交。已修正发现的问题；代码审查不替代物理手势验证或密码学审计。

触屏复用已认证的 AES-GCM 会话。Mac 本地开关、控制权限、显示器状态和输入代次共同约束事件；关闭、断线、休眠、取消和回退都会释放按下状态。Pad 发起连接采用独立的认证域和会话密钥，只允许固定的 connect / resume 请求，不能指定回连地址、启用触屏或更改画质。详见[协议](PROTOCOL.md)。

本次未重复长时间性能测试，既有 90/120 fps、HDR 亮度及延迟限制仍适用。旧版测量不能替代本版长期稳定性验证。
