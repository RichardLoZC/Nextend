# Nextend 0.7.1：刘海校准与菜单栏折叠

2026-10-19，Mac build 11，兼容已安装的 Android 0.7.0 build 10。本轮只更新 Mac。此前后台恢复功能及验证记录见 [0.7.0](RELEASE-0.7.md)。

## 使用

在 Mac 的“Pad 设置 → 刘海与菜单栏”中打开校准线，观察 Pad 物理刘海，拖动预览中的两条红线，或调整左右边界和深度。打开“图标折叠”后，刘海右边的「«」展开下方面板，显示被收起的应用图标，点击后打开对应原生菜单。桌面继续铺满 Pad，系统录屏、网络、电池等指示保留原位。极端右边界与系统指示重叠时，入口放到菜单栏下方。

校准参数自动保存，关闭设置窗口会隐藏红线。校准线无需辅助功能权限；读取和点击菜单栏图标需要为 Nextend 启用该权限。原先的四边留白保留在“画面留白”标签；折叠或校准期间暂停留白，避免坐标偏移。

## 实现与限制

Nextend 提供独立的折叠面板，不修改 macOS 原生刘海元数据，也不改变主屏菜单栏排序。原生菜单仍由原应用显示；其弹出位置由 macOS 决定。尚未验证其他 macOS 版本的辅助功能树、所有第三方菜单插件，以及长期运行表现。物理遮挡不能从系统截图测量，初始 44% / 56% 边界仍需用户看着 Pad 对齐。

读取菜单栏使用后台队列、每个 AX 对象的短超时和整轮预算。点击前匹配具体 AX 元素，等待覆盖层消失后重新确认位置及命中目标；目标消失、布局变化、用户取消或断连时放弃点击。截图仅缓存当前菜单栏于内存，布局或元素身份变化时弃用，必要时显示应用图标。

对抗性审查发现的同应用多图标误选、主线程 AX 阻塞、旧截图错配、旧打开请求污染新状态、取消后延迟点击均已处理。本轮未修改 Android，也未重复执行 0.7.0 的全部后台、HDR、无线和触控设备测试。
